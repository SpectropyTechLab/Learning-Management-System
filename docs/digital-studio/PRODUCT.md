# Product and current scope

22 September 2026. [Handbook](README.md)

Digital Studio is part of Spectropy OS, reusing its navigation, login and permissions. Content Authorizer pilot access and project owner/scope restrictions remain unchanged. Existing LMS business data must be preserved; Studio uses its separate tables.

## Four authoring stages

1. **Syllabus:** teaching context and optional existing OS curriculum links; local Board multiselect includes CBSE/NCERT, TGSCERT, APSCERT, KSEAB and MSBTE.
2. **Lesson plan:** manual entry/import of the teaching plan. Source templates are examples, not fixed formats.
3. **Slide script:** manual entry/import, supported-field mapping, review warnings and candidate append/replace. Unknown instructions are preserved rather than fabricated.
4. **Design & teach:** the original single-slide editor is the default. Authors may explicitly enable multi-block editing per slide. Save, review and present use the corresponding renderer.

## Retained local enhancements

Practical teaching activities, optional block editing/arrangement, validation/asset ownership and their tests/documentation. See CLEANUP_REVIEW.md for exact release separation. The motion-path scene is one bounded demonstration requiring separate review. The uploaded diagram in the preview is a raster asset, not editable vector geometry.

## Boundaries

No PPTX import requirement: the user requested a PowerPoint-like editor. AI is deferred. No arbitrary script-to-cinematic-scene generation, general simulation library, new role rollout or connected student workflow is claimed. The new workflow and release acceptance will be agreed next; earlier Phase 2 sequencing is no longer the active implementation instruction.

Original BRDs, prototype and discovery documents remain reference material. The source, dated test evidence and current handbook determine actual implementation status. Academic, classroom-device and production release acceptance remain distinct from passing development tests.
