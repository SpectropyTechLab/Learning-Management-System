# Supported manual script example

22 September 2026. [User guide](USER_GUIDE.md). Paste the example below into Slide script and choose Create manual slide drafts. Review before applying. The parser uses recognized fields; it is not AI. Slides remain in the default single-slide editor unless individually converted with Enable multi-block editing.

```markdown
# Slide 1: Compare shapes
Layout: concept
Visible content: A triangle has three sides. A square has four equal sides and four right angles.
Teacher notes: Ask learners to identify shapes around the classroom.

# Slide 2: Classify a property
Layout: sorting
Activity prompt: Match each property to its shape.
Categories: Triangle | Square
Sorting:
- Three sides | Triangle
- Four right angles | Square

# Slide 3: Check understanding
Layout: quiz
Question: Which shape has three sides?
Options:
- A: Triangle
- B: Square
Correct option: A
Feedback: A triangle has three sides.
```

The source remains in the session. Unsupported fields/animation instructions are flagged for manual review, not generated automatically. Review instructional accuracy before publication. Do not infer all formats or every classroom interaction are supported from this example.
